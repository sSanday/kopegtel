Host inventory overview

Halaman ini merekap field inventory yang diisi pada tiap host (menu Inventory → Hosts, ikon pensil di samping nama host).

  • Host groups menyaring host berdasarkan category-nya; klik Select untuk memilih dari daftar, atau ketik langsung di kolomnya.
  • Grouping by memilih field yang dipakai untuk mengelompokkan host (Vendor, Location, dan lainnya). Selama masih not selected, tabel sengaja dibiarkan kosong.
  • (belum diisi) berisi host yang field tersebut masih kosong.
  • Klik judul Host count untuk membalik urutan tabel.
  • Daftar per host beserta seluruh field-nya ada di menu Inventory → Hosts.
