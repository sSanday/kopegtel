Bantuan — Problems

Halaman ini menampilkan masalah (alert) gaya Zabbix dari riwayat alert NMS Kopegtel.

  • Show — Recent problems: masalah aktif + yang pulih dalam rentang; Problems: hanya aktif; History: semua status. Tombol Older / Newer / Zoom out di bar atas memperlebar atau mempersempit rentang Recent/History, atau mengubah batas Age.
  • Host groups / Hosts / Triggers / Problem — batasi daftar berdasarkan grup (kategori host), host, nama trigger (isi pesan), atau teks masalah.
  • Severity — centang level yang ingin ditampilkan. Age less than membatasi umur masalah (hari).
  • Show symptoms — tampilkan catatan/eskalasi alert sebagai gejala pada baris detail (aproksimasi dari data NMS).
  • Show suppressed problems — ikut menampilkan masalah pada host yang sedang dalam maintenance.
  • Host inventory — saring berdasarkan atribut host (Type = kategori, Name = nama host), bisa lebih dari satu baris (AND).
  • Tags — saring tag masalah (tag saat ini: type = jenis alert) dengan operator Exists, Equals, Contains, Does not exist, Does not equal, Does not contain, digabung And/Or.
  • Show tags / Tag name / Tag display priority — atur jumlah dan format tag pada kolom Tags.
  • Show operational data — tampilkan catatan operasional pada kolom Problem (terpisah atau menyatu dengan nama masalah).
  • Compact view / Show timeline / Show details / Highlight whole row — pengaturan tampilan tabel dan garis waktu.
  • Urutkan — klik header Time, Severity, Host, atau Problem. Centang baris lalu gunakan Ack selected / Unack selected untuk acknowledging massal.
  • Save as — simpan kombinasi filter sebagai tampilan; Apply menerapkan; Reset mengembalikan default.
  • Export to CSV mengunduh baris yang lolos filter. Tabel diperbarui otomatis tiap 30 detik; hitungan mundurnya ada di footer.
  • Kiosk menyembunyikan sidebar/header dan masuk layar penuh. Keluar lewat tombol Keluar kiosk atau tombol Escape.
