Bantuan — Hosts

Halaman ini menampilkan daftar host pantauan NMS Kopegtel dengan struktur dan kontrol seperti Zabbix Hosts.

  • Name / Host groups / IP / DNS / Port — saring host berdasarkan nama (atau IP), grup/kategori, alamat IP, nama DNS/alias, dan port interface (agent 10050 / SNMP 161).
  • Severity — centang level masalah yang harus dimiliki host. Host tanpa masalah aktif tidak ikut saat filter severity dipakai.
  • Status — Any / Enabled / Disabled. Semua host NMS saat ini berstatus enabled; opsi Disabled tidak menghasilkan baris sampai ada host yang dinonaktifkan.
  • Tags — tag manual dari tab Tags (New host), ditambah tag otomatis dari data nyata: class (kategori), monitoring (agent/SNMP/ping), status agent/SNMP, dan maintenance. Beberapa baris digabung dengan And/Or.
  • Macros — macro host pada tab Macros (New host) disimpan sebagai pasangan nama/nilai. Tipe Text, Secret text, dan Vault secret tersedia; nilai secret tidak dikembalikan lewat API.
  • Show hosts in maintenance — bila tidak dicentang, host yang sedang maintenance disembunyikan. Show suppressed problems — bila dicentang, jumlah masalah host maintenance tetap ditampilkan.
  • Save as — simpan kombinasi filter sebagai tampilan bernama. Apply menerapkan filter; Reset mengembalikan default.
  • Kolom Latest data, Problems, Graphs, Dashboards, dan Web membuka halaman terkait untuk host tersebut.
  • Tabel dimuat ulang otomatis setiap 30 detik tanpa menghapus filter yang aktif.
