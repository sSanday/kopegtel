Kesehatan MikroTik

Pantau CPU, memori, storage, suhu, interface, dan backup perangkat MikroTik via SNMP.

Kelola host
Panduan koneksi SNMP
  1. Aktifkan SNMP di MikroTik
    /snmp set enabled=yes
  2. Samakan community antara MikroTik dan NMS (default public).
  3. Buka firewall UDP 161 dari server NMS agar polling SNMP bisa masuk.

Unit lama yang OID-nya berbeda dapat di-override per host di menu Kelola host. Ambang dikustom lewat Pengaturan.
