Services — bantuan

Halaman ini menampilkan pemeriksaan ketersediaan layanan TCP, HTTP, ICMP, dan DNS beserta status terakhir dan riwayat latensinya.

Tombol halaman

  • ? — buka bantuan ini.
  • Create check — tambahkan pemeriksaan layanan baru.
  • View — mode baca. Klik nama layanan untuk membuka detail, grafik latency, cek SSL, dan aksi hapus.
  • Edit — mode edit. Menampilkan kolom pilih, aksi baris, dan kontrol Delete.

Filter

  • Name — saring berdasarkan nama layanan, target, atau IP.
  • Status — pilih OK, Problem, atau No data. No data berarti belum pernah diperiksa atau hasil terakhir sudah lebih dari 3 menit.
  • Service tags — isi nama tag, operator, dan value jika tag memakai format nama:nilai. Klik Add untuk menambah kondisi dan Remove untuk menghapusnya.
  • And/Or — semua kondisi harus cocok (kondisi dengan nama tag yang sama digabung dengan Or). Or — cukup salah satu kondisi yang cocok.

Mode edit

  • Centang layanan pada kolom paling kiri atau klik barisnya. Gunakan checkbox di header untuk memilih semua layanan yang tampil.
  • Delete — hapus semua layanan yang dipilih.
  • Ikon pensil mengedit layanan, dan ikon × menghapus layanan.

Dialog New / Edit check

  • Service — nama, sort order, dan description.
  • Tags — tag layanan dalam pasangan Name/Value. Klik Add untuk menambah dan Remove untuk menghapus.
  • Monitoring — tipe pemeriksaan, host/IP, port/URL/query, dan expected keyword agar layanan dapat diperiksa.

Status

  • OK — pemeriksaan terakhir berhasil dan hasilnya masih segar.
  • Problem — pemeriksaan terakhir gagal.
  • No data — belum pernah diperiksa, atau hasil terakhir sudah lebih dari 3 menit.

Klik nama layanan untuk membuka detail. Tombol Check now di detail hanya memeriksa layanan tersebut.
