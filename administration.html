Pengaturan umum

Berlaku untuk seluruh aplikasi

MFA wajib untuk peran (TOTP / aplikasi autentikator) Setelah masa tenggang habis, peran wajib tidak bisa masuk sebelum mengaktifkan MFA di menu Profil.

Data mentah yang lebih tua dari retensi dihapus setiap hari (rata-rata per jam disimpan lebih lama). Angka di bawah memperkirakan baris yang akan terhapus pada pembersihan berikutnya.

Retensi data

Berlaku mulai pembersihan harian berikutnya (02:30 / 02:35 WIB)

Pembacaan optik (DDM) - baris mentah (ikut retensi data mentah) · - rata-rata per jam (90 hari) saat ini akan terhapus.

Penerima bawaan MATI sampai diaktifkan. Hanya IP perangkat terdaftar yang diterima; pesan flow dibatasi laju & ukurannya, dan flow mentah tidak disimpan (bucket 5 menit, N teratas per kunci). Perintah MikroTik di bawah belum diuji pada versi RouterOS nyata. Verifikasi di versi RouterOS-mu.

Penerima kejadian

Syslog UDP 5514 (opsional TCP), SNMP trap UDP 1162, NetFlow UDP 2055, IPFIX UDP 4739. Community trap tersimpan tersembunyi seperti kata sandi.

Cara mengarahkan MikroTik ke NMS

Syslog: /system logging action add name=nms target=remote remote=IP-NMS remote-port=5514

/system logging add topics=info action=nms (ulangi untuk topics=warning,error,critical)

Trap: /snmp set enabled=yes contact=nms   /snmp community add name=nms addresses=IP-NMS   /snmp target add address=IP-NMS:1162 community=nms

NetFlow: /ip traffic-flow set enabled=yes cache-active-flow-timeout=01:00:00   /ip traffic-flow target add address=IP-NMS:2055 version=9 (atau version=ipfix / port 4739)

Untuk ifIndex → nama antarmuka, modul MikroTik harus menarik /interface/print (field if-index). Verifikasi di versi RouterOS-mu.

Retensi & batas laju kejadian

Syslog bawaan 14 hari, trap 30 hari. Antrean disimpan per kelompok (bawaan 200 baris/kuras).
