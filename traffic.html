Belum ada data flow

Aktifkan penerima NetFlow/IPFIX, lalu arahkan traffic-flow MikroTik ke server NMS. Data akan muncul di sini setelah paket flow pertama diterima.

Panduan singkat
  1. Aktifkan NetFlow UDP (port 2055) atau IPFIX UDP (port 4739) di Administrasi → Penerima kejadian.
  2. Arahkan target traffic-flow RouterOS ke alamat server NMS.
/ip traffic-flow set enabled=yes cache-active-flow-timeout=01:00:00
/ip traffic-flow target add address=IP-NMS:2055 version=9

Contoh perintah, sesuaikan alamatnya dan verifikasi pada versi RouterOS Anda.
