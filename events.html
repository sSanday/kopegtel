Belum ada syslog masuk

Pesan syslog akan tampil di sini setelah penerima aktif dan perangkat mengirimkannya.

  1. Aktifkan Syslog UDP di Administrasi → Penerima kejadian.
  2. Arahkan logging RouterOS ke alamat server NMS, port 5514.
/system logging action add name=nms target=remote remote=IP-NMS remote-port=5514
/system logging add topics=info action=nms

Contoh perintah—sesuaikan alamatnya dan verifikasi pada versi RouterOS Anda.

Belum ada trap masuk

Trap SNMP akan tampil di sini setelah penerima aktif dan perangkat mengirimkannya.

  1. Aktifkan SNMP trap UDP di Administrasi → Penerima kejadian.
  2. Arahkan target SNMP RouterOS ke alamat server NMS, port 1162.
/snmp community add name=nms addresses=IP-NMS
/snmp target add address=IP-NMS:1162 community=nms

Contoh perintah—sesuaikan alamatnya dan verifikasi pada versi RouterOS Anda.
